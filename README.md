# Selah — Praise & Worship Planner

A lightweight, responsive worship planning app for song libraries, setlists, service calendars, and team lineups.

## Features
- Maintain a song library with artist, key, BPM, category, notes, and lyrics/chord-chart links.
- Build and save reusable setlists.
- Schedule services on a monthly calendar.
- Store a separate song lineup and team assignments for each service.
- Copy a previous service to a new date, including its lineup, without changing the original.
- Export and import JSON backups.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. After the first deployment finishes, the site will be available at `https://tasyooo.github.io/praise-worship-planner/`.

## Data and privacy
Planner data is stored in the browser's local storage on the device/browser where you use the app. It is not automatically synced between devices. Use **Export backup** to save your data, and **Import backup** to restore it.
